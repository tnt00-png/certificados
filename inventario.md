## Campos Sugeridos para Futuros Certificados

Para mantener un inventario organizado, considera incluir:

- **Nombre del certificado**
- **Entidad emisora**
- **Fecha de emisión**
- **Fecha de vencimiento** (si aplica)
- **Número de certificado**
- **Área/categoría** (profesional, académico, técnico)
- **Nivel/grado**
- **Descripción breve**
- **Archivos relacionados**

## Recomendaciones

1. **Renombrar archivos** con convención descriptiva
   - Ejemplo: `2024_Certificado_[Nombre]_[Entidad].pdf`

2. **Crear carpetas por categoría**
   - `profesionales/`
   - `academicos/`
   - `tecnicos/`

3. **Mantener múltiples formatos**
   - PDF para archivo oficial
   - Imagen para visualización rápida

4. **Documentar metadatos** en este inventario para cada nuevo certificado
